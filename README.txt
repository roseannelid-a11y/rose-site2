77 BIRCH COURT PROPERTY WEBSITE
================================

Files
- index.html: property listing page
- styles.css: responsive styling
- netlify.toml: basic Netlify configuration
- images/: add the four actual property photos here

ADD THE ACTUAL PHOTOS
Use your real photos only. No photos were attached when this project was generated, so the page shows labeled placeholders until the files are added.

Save the photos using these exact filenames:
- images/front.jpg
- images/living-room.jpg
- images/kitchen.jpg
- images/balcony.jpg

If your photos are PNG or WebP, either convert them to JPG or update the matching image filename in index.html.

DEPLOY TO NETLIFY
1. Extract this ZIP file.
2. Add the four actual photos to the images folder.
3. Open Netlify and sign in.
4. Drag the extracted project folder (or its contents, including index.html, styles.css, netlify.toml, and images/) into Netlify's manual deploy area.
5. Open the generated site URL and check it on mobile and desktop.

CONTENT NOTE
The page uses only the facts provided in the request. It does not add unprovided property details or use stock photos.
